Data

Leverage Factor

Used in "Financial Intermediaries and the Cross-Section of Asset Returns" (with Adrian and Etula), Journal of Finance 2014

  • Original Leverage Factor Data (.xlsx)

    Quarterly, 1968–2009. This is the exact data vintage used in the published paper.

  • Extended Leverage Factor Data (.csv)

    Quarterly, 1968–2025. Contains two columns: (1) the original paper-vintage factor extended by appending new Flow of Funds observations, and (2) the factor recomputed using revised Flow of Funds data over the full sample. The two differ because FRED revised its historical broker-dealer series (gross vs. net repo treatment). Both columns are identical from 2016Q3 onward.

Volatility-Managed Factor Returns

From "Volatility-Managed Portfolios" (with Moreira), Journal of Finance 2017

  • Six-Factor File (.csv)

    Monthly, 1963–2026. Vol-managed and original returns for Mkt-RF, SMB, HML, RMW, CMA, and Momentum.

  • Long-History Four-Factor File (.csv)

    Monthly, 1927–2026. Vol-managed and original returns for Mkt-RF, SMB, HML, and Momentum. Starts earlier because RMW and CMA are only available from 1963.

Each month’s vol-managed return scales the factor by the ratio of full-sample variance to realized variance (from daily returns within the prior month). Underlying data from Kenneth French’s data library. Returns are in percent (e.g., 5.0 = 5%). Updated periodically.
